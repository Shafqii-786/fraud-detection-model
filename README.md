# AI-Driven Enterprise Fraud Detection

**Domain:** Cybersecurity & Risk Analytics  
**Technologies Used:** Python, Pandas, Scikit-Learn (Random Forest Classifier)  

### Executive Summary
This project implements an advanced machine learning classification pipeline designed to identify anomalous and fraudulent transactions within highly imbalanced enterprise datasets. 

### Technical Implementation
* **Algorithmic Modeling:** Engineered and trained a Random Forest ensemble algorithm to accurately categorize data points as either legitimate or fraudulent.
* **Performance Optimization:** Successfully achieved a 97% overall accuracy rate.
* **Enterprise Evaluation:** Validated model robustness and reliability using advanced precision, recall, and F1-score metrics, demonstrating readiness for real-world cybersecurity applications.

### Core Competencies Demonstrated
* Translates theoretical probability and algorithmic logic into functional risk-management software.
* Evaluates complex classification reports beyond simple accuracy, a critical skill for managing enterprise IT infrastructure.
